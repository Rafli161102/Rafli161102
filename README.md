<h2><img src="https://api.iconify.design/lucide/user-round.svg?color=%23426EA5" width="22" height="22" alt="" /> About</h2>

I'm Rafli — a **graphic designer and creative explorer** interested in visual identity, print production, digital experiences, and creative communities.

I also use **vibe coding** to explore web ideas. AI tools help me turn concepts into prototypes; I focus on the brief, visual direction, user flow, testing, and refinement. I'm not presenting myself as a traditional software engineer. I learn by building, reviewing what works, and improving the result.

My design approach is simple: **make it clear, make it useful, and take care of the details.**

<h2><img src="https://api.iconify.design/lucide/move-diagonal-2.svg?color=%23426EA5" width="22" height="22" alt="" /> Motion Studies</h2>

These custom SVG experiments explore layout, rhythm, typography, and colour. SVG artwork switches between light and dark versions according to the viewing environment's colour-scheme preference.

**01 — Kinetic Layout**

Six modules move and resize directly between three measured compositions—balanced grid, feature-led, and sidebar. Each panel displays its width × height in pixels plus its relative area compared with a 340 × 126 px reference tile. Labels pause during movement so the measurements never imply a size mid-transition. No fade animation is used for the layouts.
